# Contributing to Smart Bill Splitter

Thank you for your interest in contributing to **Smart Bill Splitter**!

## How to Contribute

1. **Fork the Repository** on GitHub.
2. **Clone your fork**:
   ```bash
   git clone https://github.com/albar-rahman/smart-bill-splitter.git
   cd smart-bill-splitter
   ```
3. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/awesome-improvement
   ```
4. **Make Changes**:
   - Write clean, modular Java code conforming to OOP standards.
   - Use BigDecimal for monetary and precision calculations.
   - Include unit tests in src/test/java/ where appropriate.
5. **Submit a Pull Request** against the main branch with a clear description of your changes.
